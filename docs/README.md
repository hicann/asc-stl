# 项目文档

ASC-STL是面向Ascend C核函数开发的纯头文件C++ 库，提供C++ 标准库接口、昇腾扩展接口和Runtime接口。

## 目录说明

```text
docs/
├── zh/             # 中文文档
│   ├── api/        # API 参考
│   ├── contributing/ # 贡献指南
│   ├── examples/   # API 示例源码
│   ├── figures/    # 文档图片
│   └── guide/      # 获取、使用、构建与测试
├── en/             # 英文文档（建设中）
├── README.md       # 中文文档入口
└── README_en.md    # 英文文档入口
```
