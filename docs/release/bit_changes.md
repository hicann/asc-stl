# `<asc/bit>` 位操作契约

对应 [Issue #90](https://gitcode.com/cann/asc-stl/issues/90)。本头提供
`bit_reverse`、`bitfield_extract`、`bitfield_insert` 和 `bitmask`，最低 C++17，同时支持 C++20。
四个函数均按值返回，支持常量求值且不抛出异常。

## 类型与调用环境

模板类型必须与 `asc::std::uint32_t` 或 `asc::std::uint64_t` 相同；仅位宽相同的另一种
整数类型不自动匹配。无效类型现在从重载集合排除，可直接用于可调用性检测。
普通按值推导去掉顶层 cv 限定，显式 cv/ref 模板类型不属于支持域。

插入的两个值实参共同推导同一类型。需要转换时，可显式选择支持的模板类型，遵循
普通 C++ 值参数转换规则。`bitmask` 默认 32 位；64 位掩码需显式选择 `uint64_t`。

Host、SIMT 线程与 SIMD 核的普通标量代码使用相同的整数值语义。位编号从最低有效位
0 开始，独立于内存字节序和 C++ 位域成员布局；本头不操作向量或掩码寄存器。

## 区间结果

令 `W` 为结果类型的位宽，合法区间满足
`0 <= start && start <= W && 0 <= width && width <= W - start`。

| 情况 | 提取 | 插入 | 掩码 |
| --- | --- | --- | --- |
| 合法非空区间 | 字段右对齐，高位补零 | 替换源的低 `width` 位，保留目标其他位 | 原区间为一，其他位为零 |
| 零宽，包括 `(W, 0)` | 零 | 原目标值 | 零 |
| `(0, W)` | 原输入值 | 源值 | 全一 |
| 非法区间，包括负数及任意 `int` 极值 | 零 | 原目标值 | 零 |

原先 extract/insert 的调试断言和发布版截短行为由上述统一规则替代。参数不会截断或
取模；需要区分非法输入与合法零结果的调用方自行检查区间。所有边界在实际移位前处理。

## 验证入口

独立的 `asc/bit` Host、Device 和运行时用例覆盖两个位宽，逐位参考不调用被测 API。
Host 用例覆盖全部合法窗口、极值参数和位反转/插入性质；运行时用例从设备内存读入
动态参数，以同一组独立预期核对 SIMD/SIMT 的四个接口。

按仓库测试选项配置后，可选择 `semantic.host.cxx17.asc.bit`、
`semantic.host.cxx20.asc.bit` 以及 `runtime.cannsim.bit.simd/simt`，无需扩大为整库测试。
运行时项目的 `ASC_STL_BIT_SIMULATION` 区分模拟器与显式硬件入口，云端检查仅调用模拟器。
