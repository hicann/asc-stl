# Bit Operations, Math and Numeric Computation, Pseudorandom Numbers

Bit operations, math utilities, numeric computation, and random numbers.

| Header | Description |
| --- | --- |
| [asc/bit](asc_bit/asc_bit.md) | Provides bit reversal, mask generation, and bit field extraction and insertion for unsigned 32-bit and 64-bit integers |
| [asc/cmath](asc_cmath/asc_cmath.md) | Provides integer division rounding, logarithm, square root, high half of a product, and integer power operations, plus the `sincos` function available in Host and AI Core SIMT programming |
| [asc/numeric](asc_numeric/asc_numeric.md) | Provides integer overflow detection, saturating arithmetic, and checked narrowing type conversion |
| [asc/random](asc_random/asc_random.md) | Provides the deterministic PCG64 pseudorandom number engine, and `random_bijection`, a deterministic bijection over a finite integer domain |
