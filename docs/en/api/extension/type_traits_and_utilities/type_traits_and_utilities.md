# Type Traits, Utilities and Version Detection

Extended type traits, utilities, and version detection.

| Header | Description |
| --- | --- |
| [asc/type_traits](asc_type_traits/asc_type_traits.md) | Provides type traits for properties such as bitwise comparability, extended floating-point types, and trivial relocatability |
| [asc/utility](asc_utility/asc_utility.md) | `in_range` determines whether a value lies within a closed interval, and `static_for` executes a compile-time loop a fixed number of times |
| [asc/version](asc_version/asc_version.md) | Provides ASC-STL version macros and feature-detection macros for available extensions |
