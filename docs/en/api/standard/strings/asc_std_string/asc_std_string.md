# Header asc/std/string

Provides string types that own character sequences

## Usage

```cpp
#include <asc/std/string>
```

When combining long strings, local arenas, and aliasing operations in AI Core SIMT programming, follow the [toolchain verification boundaries of basic_string](basic_string.md#toolchain-verification-boundaries-in-ai-core-simt-programming).
