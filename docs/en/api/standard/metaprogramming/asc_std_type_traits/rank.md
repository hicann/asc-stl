## Description

Header: `<asc/std/type_traits>`.

`asc::std::rank` obtains the number of dimensions of an array type.

Standard semantics reference: [cppreference `type_traits`](https://en.cppreference.com/w/cpp/header/type_traits).

## Declaration

```cpp
namespace asc::std {
template<class T> struct rank;
} // namespace asc::std
```

## Constraints

- Provides the trait class and the _v helper form.

## Example

The following Host snippet verifies the result of the type trait on this page with concrete type arguments and `static_assert`.

```cpp
#include <asc/std/type_traits>

void use_trait()
{
    // Positive example: the rank of an array is its number of dimensions; the two-dimensional array int[2][3] has rank 2
    static_assert(asc::std::rank<int[2][3]>::value == 2);
    static_assert(asc::std::rank_v<int[4]> == 1);
    // Counterexample: the rank of the non-array type int is 0
    static_assert(asc::std::rank_v<int> == 0);
}
```
