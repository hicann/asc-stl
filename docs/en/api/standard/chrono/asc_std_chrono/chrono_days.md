## Description

Header: `<asc/std/chrono>`.

`asc::std::chrono::days` is an integer-count duration of 86400 seconds per tick, convertible with other `duration`s.

Standard semantics reference: [cppreference `chrono`](https://en.cppreference.com/w/cpp/header/chrono).

## Declaration

```cpp
namespace asc::std::chrono {
using days = duration<int, ratio_multiply<ratio<24>, hours::period>>;
} // namespace asc::std::chrono
```

## Constraints

- Provides value operations and the six explicit relational operators.

## Example

The following Host example provides concrete inputs and checks the result of the call.

```cpp
#include <asc/std/chrono>
#include <asc/std/limits>

bool example()
{
    asc::std::chrono::days first{2}, second{3};
    return (first + second).count() == 5;
}
```
