## Description

Header: `<asc/std/chrono>`.

`asc::std::chrono::year_month_day_last` represents the last day of a month of a year; day() is computed from the length of that month and the leap year rule, and the month must be valid.

Standard semantics reference: [cppreference `chrono`](https://en.cppreference.com/w/cpp/header/chrono).

## Declaration


## Example

The following Host example provides concrete inputs and checks the result of the call.

```cpp
#include <asc/std/chrono>
#include <asc/std/limits>

bool example()
{
    asc::std::chrono::year_month_day_last value{asc::std::chrono::year{2024}, asc::std::chrono::month_day_last{asc::std::chrono::month{2}}};
    return static_cast<unsigned int>(value.day()) == 29;
}
```
