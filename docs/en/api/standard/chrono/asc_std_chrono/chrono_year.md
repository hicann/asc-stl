## Description

Header: `<asc/std/chrono>`.

`asc::std::chrono::year` stores the Gregorian year field, with a valid range of -32767 to 32767; it provides leap year determination, and year 0 and negative years follow the extended Gregorian calendar.

Standard semantics reference: [cppreference `chrono`](https://en.cppreference.com/w/cpp/header/chrono).

## Declaration

```cpp

} // namespace asc::std::chrono
```
