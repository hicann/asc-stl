## Description

Header: `<asc/std/chrono>`.

`asc::std::chrono::year::~year` destroys a `year` object and ends its lifetime.

Standard semantics reference: [cppreference `chrono`](https://en.cppreference.com/w/cpp/header/chrono).

## Function Prototype

The C++17 form is as follows; the destructor is implicitly generated by the compiler, and from C++20 it is usable in constant evaluation when the conditions are met.

```cpp
~year() noexcept;
```

## Parameters

No parameters.

## Return Value

No return value.

## Constraints

- Operations on calendar fields and timekeeping values are available on Host and in supported AI Core programming modes; date validity is determined by the corresponding `ok()` member.

## Example

The following snippet assumes that object points to a constructed object; after explicit destruction the object must not be accessed again, and releasing the storage is the caller's responsibility.

```cpp
#include <asc/std/chrono>
#include <new>
#include <type_traits>

bool example()
{
    namespace chrono = asc::std::chrono;
    using value_type = chrono::year;
    static_assert(::std::is_trivially_destructible_v<value_type>);
    alignas(value_type) unsigned char storage[sizeof(value_type)];
    auto* value = ::new (static_cast<void*>(storage)) value_type(chrono::year{2024});
    value->~value_type();
    value = ::new (static_cast<void*>(storage)) value_type(chrono::year{2024});
    const bool restored = static_cast<int>((*value)) == 2024;
    value->~value_type();
    return restored;
}
```
