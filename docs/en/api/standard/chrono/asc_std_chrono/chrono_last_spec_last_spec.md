## Description

Header: `<asc/std/chrono>`.

`asc::std::chrono::last_spec::last_spec` initializes a `last_spec` object according to the construction forms listed on this page.

Standard semantics reference: [cppreference `chrono`](https://en.cppreference.com/w/cpp/header/chrono).

## Function Prototype

last_spec is an empty tag type; the default constructor is explicit, and copy and move construction are implicitly generated by the compiler.

```cpp
explicit last_spec() = default;
```

## Parameters

The default constructor takes no parameters. The compiler-generated copy and move constructors accept another last_spec object, copying only the empty tag and transferring no resources.

## Return Value

No return value.

## Constraints

- Operations on calendar fields and timekeeping values are available on Host and in supported AI Core programming modes; date validity is determined by the corresponding `ok()` member.

The following Host example provides concrete inputs and checks the result of the call.

```cpp
#include <asc/std/chrono>
```
