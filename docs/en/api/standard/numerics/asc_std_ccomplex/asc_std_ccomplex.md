# Header asc/std/ccomplex

Compatibility header that forwards to the C++ complex header asc/std/complex

## Usage

```cpp
#include <asc/std/ccomplex>
```

## API List

| API | Kind | C++ Mode | Availability | Product Support |
| --- | --- | --- | --- | --- |

This header forwards to [`asc/std/complex`](../asc_std_complex/asc_std_complex.md); its interfaces, type domains, and execution availability are identical to that header, and it does not separately define the C language _Complex type.
