## Description

Header: `<asc/std/cmath>`.

`asc::std::fmodf` computes the floating-point remainder corresponding to the truncated quotient; on the device side, the applicable scope is subject to the float and execution-location constraints on this page.

This interface is available on Host and in AI Core SIMT programming.

Standard semantics reference: [cppreference `cmath`](https://en.cppreference.com/w/cpp/header/cmath).

## Function Prototype

Each overload is available starting from C++17. Execution-location restrictions are described per prototype below; execution-location macros are omitted.

### Prototype 1

```cpp
namespace asc::std {
[[nodiscard]] constexpr float fmodf(
    float x, float y) noexcept;
}
```

Available locations: Host, AI Core SIMT programming. The following constexpr applies to Host; the Device declaration is not constexpr and the call is executed at run time.

## Parameters

**Function Parameters**

| Parameter | Input/Output | Description |
| --- | --- | --- |
| `x` | Input | Dividend of the floating-point remainder operation (dimensionless). |
| `y` | Input | Divisor of the floating-point remainder operation (dimensionless, must be non-zero; returns NaN when it is 0). |

## Return Value

The return type is determined per prototype (`float`). Returns the remainder computed with the quotient truncated toward zero; a non-zero result has the sign of the dividend.

## Constraints

- Maintains the mathematical domain and pointer validity requirements in the parameters description; availability and language conditions are determined per prototype.

## Example

The following Host example provides concrete inputs and expected results.

```cpp
#include <asc/std/cmath>

bool example()
{
    const auto result = asc::std::fmodf(5.0F, 2.0F);
    return result == 1.0F;
}
```
