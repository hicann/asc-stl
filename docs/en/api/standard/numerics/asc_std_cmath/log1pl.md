## Description

Header: `<asc/std/cmath>`.

`asc::std::log1pl` is provided by `<asc/std/cmath>`; Host long double log(1+x), the suffix-l alias.

Standard semantics reference: [cppreference `cmath`](https://en.cppreference.com/w/cpp/header/cmath).

## Function Prototype

Each overload is available starting from C++17. Execution-location restrictions are described per prototype below; execution-location macros are omitted.

### Prototype 1

```cpp
namespace asc::std {
[[nodiscard]] constexpr long double log1pl(long double value) noexcept;
}
```

Available locations: Host. The long double related overloads require Host to have support for this type enabled.

## Parameters

**Function Parameters**

| Parameter | Input/Output | Description |
| --- | --- | --- |
| `value` | Input | Input value for computing ln(1 + x) (dimensionless); the domain is (-1, +∞), -1 returns -inf, values less than -1 return NaN, and precision is preserved for inputs close to 0. |

## Return Value

The return type is determined per prototype (`long double`). Returns the natural logarithm of 1 plus the input, improving precision for inputs close to zero.

## Constraints

- Host long double log(1+x), suffix-l alias.

## Example

The following Host example provides concrete inputs and expected results.

```cpp
#include <asc/std/cmath>

bool example()
{
    const auto result = asc::std::log1pl(0.0L);
    return result == 0.0L;
}
```
