# Header asc/std/ctgmath

Compatibility header that combines the C++ math and complex overloads

## Usage

```cpp
#include <asc/std/ctgmath>
```

## API List

| API | Kind | C++ Mode | Availability | Product Support |
| --- | --- | --- | --- | --- |

This header combines the C++ overloads of [`asc/std/cmath`](../asc_std_cmath/asc_std_cmath.md) and [`asc/std/complex`](../asc_std_complex/asc_std_complex.md); it does not provide independent C language generic macros.
