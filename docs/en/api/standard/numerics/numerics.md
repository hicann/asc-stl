# Numerics Library

Mathematical functions, complex numbers, random numbers, and numeric operations.

| Header | Function |
| --- | --- |
| [asc/std/cmath](asc_std_cmath/asc_std_cmath.md) | Provides common scalar mathematical functions and floating-point classification capabilities |
| [asc/std/ccomplex](asc_std_ccomplex/asc_std_ccomplex.md) | Compatibility header that forwards to the C++ complex header asc/std/complex |
| [asc/std/complex](asc_std_complex/asc_std_complex.md) | Provides complex number types, arithmetic operations, and complex mathematical functions |
| [asc/std/ctgmath](asc_std_ctgmath/asc_std_ctgmath.md) | Compatibility header that combines C++ mathematical and complex overloads |
| [asc/std/linalg](asc_std_linalg/asc_std_linalg.md) | Provides linear algebra algorithms for vector and matrix views |
| [asc/std/numbers](asc_std_numbers/asc_std_numbers.md) | Provides standard mathematical constants such as pi and the natural constant |
| [asc/std/random](asc_std_random/asc_std_random.md) | Provides random number engines, distributions, and random number generation helpers |
| [asc/std/numeric](asc_std_numeric/asc_std_numeric.md) | Provides numerical algorithms such as reduction, scan, inner product, difference, and sequence generation |
