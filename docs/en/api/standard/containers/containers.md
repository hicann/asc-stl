# Containers Library

Sequence containers, associative containers, and their adaptors.

| Header | Function |
| --- | --- |
| [asc/std/array](asc_std_array/asc_std_array.md) | Provides a contiguous sequence container with a fixed compile-time length |
| [asc/std/deque](asc_std_deque/asc_std_deque.md) | Provides a sequence container supporting insertion and removal at both ends |
| [asc/std/forward_list](asc_std_forward_list/asc_std_forward_list.md) | Provides a singly linked sequence container |
| [asc/std/inplace_vector](asc_std_inplace_vector/asc_std_inplace_vector.md) | Provides a contiguous sequence with fixed capacity and variable current length |
| [asc/std/list](asc_std_list/asc_std_list.md) | Provides a doubly linked sequence container |
| [asc/std/map](asc_std_map/asc_std_map.md) | Provides key-value associative containers ordered by key |
| [asc/std/mdspan](asc_std_mdspan/asc_std_mdspan.md) | Provides a non-owning indexed view over existing multidimensional data |
| [asc/std/queue](asc_std_queue/asc_std_queue.md) | Provides first-in first-out queue and priority queue adaptors |
| [asc/std/set](asc_std_set/asc_std_set.md) | Provides associative containers ordered by unique keys |
| [asc/std/span](asc_std_span/asc_std_span.md) | Provides a non-owning view over an existing contiguous sequence of elements |
| [asc/std/stack](asc_std_stack/asc_std_stack.md) | Provides a last-in first-out container adaptor |
| [asc/std/unordered_map](asc_std_unordered_map/asc_std_unordered_map.md) | Provides hash-organized key-value associative containers |
| [asc/std/unordered_set](asc_std_unordered_set/asc_std_unordered_set.md) | Provides hash-organized associative containers with unique keys |
| [asc/std/vector](asc_std_vector/asc_std_vector.md) | Provides a sequence container with contiguous storage and dynamically changeable length |
