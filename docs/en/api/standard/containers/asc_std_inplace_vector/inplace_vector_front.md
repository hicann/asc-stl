## Description

Header: `<asc/std/inplace_vector>`.

`asc::std::inplace_vector::front` returns a reference to the first element; the object must be non-empty.

This interface supports both Host and the device side, both limited to the non-throwing operations listed on this page.

Standard semantics reference: [cppreference `inplace_vector`](https://en.cppreference.com/w/cpp/header/inplace_vector).

## Function Prototype

Member of: [`inplace_vector<T, Capacity>`](inplace_vector.md). The following is the in-class declaration; type aliases and template parameters are provided by the owning class.

### Prototype 1

```cpp
constexpr reference front() noexcept;
```

### Prototype 2

```cpp
constexpr const_reference front() const noexcept;
```

## Parameters

No parameters.

## Return Value

| Applicable prototype | Return type | Description |
| --- | --- | --- |
| Prototype 1 | `reference` | A writable reference borrowing the first element; the element must remain alive for the duration of use. |
| Prototype 2 | `const_reference` | A read-only reference borrowing the first element; the element must remain alive for the duration of use. |

## Constraints

- The container must be non-empty before the call; a removed element's lifetime ends.

## Example

The following Host example provides concrete inputs and checks the result of the call.

```cpp
#include <asc/std/inplace_vector>

bool example()
{
    asc::std::inplace_vector<int, 4> values;
    if (!values.try_push_back(1)) return false;
    if (!values.try_push_back(3)) return false;
    return values.front() == 1;
}
```
