# Language Support Library

Fundamental types, feature macros, source locations, and language facilities.

| Header | Function |
| --- | --- |
| [asc/std/cfloat](asc_std_cfloat/asc_std_cfloat.md) | Provides macros describing the precision, range, and representation characteristics of floating-point types |
| [asc/std/climits](asc_std_climits/asc_std_climits.md) | Provides range macros for the fundamental integer types |
| [asc/std/cstddef](asc_std_cstddef/asc_std_cstddef.md) | Provides fundamental types such as `size_t`, `ptrdiff_t`, `nullptr_t`, and `byte` |
| [asc/std/cstdint](asc_std_cstdint/asc_std_cstdint.md) | Provides signed and unsigned fixed-width integer types |
| [asc/std/exception](asc_std_exception/asc_std_exception.md) | Provides the exception base types, termination handling, and current-exception query facilities |
| [asc/std/compare](asc_std_compare/asc_std_compare.md) | Provides three-way comparison result categories and comparison utilities |
| [asc/std/new](asc_std_new/asc_std_new.md) | Provides memory allocation function declarations, placement new, and related types |
| [asc/std/limits](asc_std_limits/asc_std_limits.md) | Provides the minimum, maximum, precision, and representation properties of numeric types |
| [asc/std/source_location](asc_std_source_location/asc_std_source_location.md) | Provides source location information such as the file name, function name, line, and column |
| [asc/std/version](asc_std_version/asc_std_version.md) | Provides feature-testing macros for standard features |
| [asc/std/ciso646](asc_std_ciso646/asc_std_ciso646.md) | Provides C-compatible spellings of operators such as `and`, `or`, and `not` |
| [asc/std/cstdalign](asc_std_cstdalign/asc_std_cstdalign.md) | Provides a C-compatible definition of the alignment keyword |
| [asc/std/cstdbool](asc_std_cstdbool/asc_std_cstdbool.md) | Provides a C-compatible definition of the boolean type |
