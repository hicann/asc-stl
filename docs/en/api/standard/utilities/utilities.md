# General Utilities Library

General objects, function objects, and value manipulation utilities.

| Header | Function |
| --- | --- |
| [asc/std/cstdlib](asc_std_cstdlib/asc_std_cstdlib.md) | Provides C standard library compatible functionality such as numeric conversions and absolute values |
| [asc/std/bit](asc_std_bit/asc_std_bit.md) | Provides counting, rotation, byte swapping, and bit-level conversion operations |
| [asc/std/bitset](asc_std_bitset/asc_std_bitset.md) | Provides fixed-length bit sets determined at compile time |
| [asc/std/expected](asc_std_expected/asc_std_expected.md) | Provides a type that expresses either a success result or an error value |
| [asc/std/functional](asc_std_functional/asc_std_functional.md) | Provides function objects, callable object wrappers, invocation, and binding utilities |
| [asc/std/optional](asc_std_optional/asc_std_optional.md) | Provides objects that may or may not contain a value |
| [asc/std/tuple](asc_std_tuple/asc_std_tuple.md) | Provides the `tuple` type that combines multiple values of different types into one object |
| [asc/std/utility](asc_std_utility/asc_std_utility.md) | Provides move, forward, swap, integer sequences, and general helper utilities |
| [asc/std/variant](asc_std_variant/asc_std_variant.md) | Provides a type-safe union object that holds one current value among multiple alternative types |
