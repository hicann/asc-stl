# Text Processing Library

Character classification, conversion, and text formatting.

| Header | Functionality |
| --- | --- |
| [asc/std/cctype](asc_std_cctype/asc_std_cctype.md) | Provides narrow character classification, case tests, and case conversion |
| [asc/std/charconv](asc_std_charconv/asc_std_charconv.md) | Provides locale-independent conversion between character sequences and numeric values |
| [asc/std/cuchar](asc_std_cuchar/asc_std_cuchar.md) | Provides conversion between multibyte characters and UTF-16 and UTF-32 characters |
| [asc/std/cwchar](asc_std_cwchar/asc_std_cwchar.md) | Provides wide character types, conversion, and wide string operations |
| [asc/std/cwctype](asc_std_cwctype/asc_std_cwctype.md) | Provides wide character classification, case tests, and case conversion |
| [asc/std/format](asc_std_format/asc_std_format.md) | Provides type-safe format string parsing and formatting |
