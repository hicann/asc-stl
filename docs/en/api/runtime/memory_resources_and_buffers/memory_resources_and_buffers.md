# Memory Resources, Memory Pools, and Buffers

Device memory resources, memory pools, and owning buffers.

| Header | Description |
| --- | --- |
| [asc/memory_resource](asc_memory_resource/asc_memory_resource.md) | Provides resource objects for device memory and Host pinned memory, non-owning references, and explicit allocation and deallocation interfaces |
| [asc/memory_pool](asc_memory_pool/asc_memory_pool.md) | Reuses memory blocks only after an Event completes, with support for memory reclamation and status statistics |
| [asc/buffer](asc_buffer/asc_buffer.md) | Provides buffers that create and manage contiguous memory based on a specified memory resource |
