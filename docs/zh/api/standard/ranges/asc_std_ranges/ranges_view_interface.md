## 功能说明

头文件路径为：`<asc/std/ranges>`。

`asc::std::ranges::view_interface` 标记临时范围的不可借用结果或提供视图适配辅助能力。

标准语义参考：[cppreference `ranges`](https://en.cppreference.com/w/cpp/header/ranges)。

## 声明

```cpp
template<class Derived> class asc::std::ranges::view_interface
```

## 约束说明

- C++20 视图不进行动态内存分配
- owning_view 仅拥有调用方传入的范围对象，不产生额外分配

## 调用示例

以下片段演示本页接口的基本调用形式；输入和执行上下文须满足本页约束。

```cpp
#include <asc/std/ranges>

void use_type()
{
    using selected = asc::std::ranges::view_interface<asc::std::ranges::single_view<int>>;
    (void)sizeof(selected);
}
```
