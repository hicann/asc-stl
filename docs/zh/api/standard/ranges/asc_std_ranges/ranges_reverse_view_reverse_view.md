## 功能说明

头文件路径为：`<asc/std/ranges>`。

`asc::std::ranges::reverse_view::reverse_view`按本页所列构造形态初始化`reverse_view`对象。

标准语义参考：[cppreference `ranges`](https://en.cppreference.com/w/cpp/header/ranges)。

## 函数原型

### 原型1

```cpp
reverse_view();
```

### 原型2

```cpp
constexpr reverse_view(View base);
```

## 参数说明

### 原型1的参数

无参数。

### 原型2的参数

**函数参数**

| 参数名 | 输入/输出 | 描述 |
| --- | --- | --- |
| `base` | 输入 | 被反转呈现的底层视图；须为双向范围，视图按相反顺序呈现其元素。 |

## 返回值说明

无返回值。

## 约束说明

- 视图的元素访问与迭代不额外分配存储；底层范围的生命周期须覆盖所有借用视图的使用。

## 调用示例

以下Host示例给出具体输入，并检查调用结果。

```cpp
#include <asc/std/ranges>
#include <asc/std/array>
#include <asc/std/iterator>
#include <asc/std/tuple>

bool example()
{
    int values[] = {1, 2, 3, 4};
    using Base = asc::std::ranges::subrange<int*>;
    Base base(values, values + 4);
    asc::std::ranges::reverse_view<Base> view(base);
    return *view.begin() == 4;
}
```
