# 通用工具库

通用对象、函数对象与值操作工具。

| 头文件 | 功能 |
| --- | --- |
| [asc/std/cstdlib](asc_std_cstdlib/asc_std_cstdlib.md) | 提供数值转换、绝对值等C标准库兼容功能 |
| [asc/std/bit](asc_std_bit/asc_std_bit.md) | 提供计数、旋转、字节交换和位级转换等操作 |
| [asc/std/bitset](asc_std_bitset/asc_std_bitset.md) | 提供编译期固定长度的位集合 |
| [asc/std/expected](asc_std_expected/asc_std_expected.md) | 提供同时表达成功结果或错误值的类型 |
| [asc/std/functional](asc_std_functional/asc_std_functional.md) | 提供函数对象、可调用对象包装、调用和绑定工具 |
| [asc/std/optional](asc_std_optional/asc_std_optional.md) | 提供可能包含或不包含值的对象 |
| [asc/std/tuple](asc_std_tuple/asc_std_tuple.md) | 提供将多个不同类型值组合为一个对象的`tuple`类型 |
| [asc/std/utility](asc_std_utility/asc_std_utility.md) | 提供移动、转发、交换、整数序列和通用辅助工具 |
| [asc/std/variant](asc_std_variant/asc_std_variant.md) | 提供在多个候选类型之间保存一个当前值的类型安全联合对象 |
