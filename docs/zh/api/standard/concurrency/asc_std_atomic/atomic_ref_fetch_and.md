## 功能说明

头文件路径为：`<asc/std/atomic>`。

`asc::std::atomic_ref::fetch_and` 原子执行按位与并返回修改前的值。

该接口的可用位置为 Host、AI Core SIMT 编程。

标准语义参考：[cppreference `atomic`](https://en.cppreference.com/w/cpp/header/atomic)。

## 函数原型

```cpp
T asc::std::atomic_ref::fetch_and(T value, asc::std::memory_order order = asc::std::memory_order_seq_cst) const noexcept;
```

## 参数说明

**函数参数**

| 参数名 | 输入/输出 | 描述 |
| --- | --- | --- |
| `value` | 输入 | 与目标对象当前值做按位与的整数值。 |
| `order` | 输入 | 本次操作的内存序，默认为 memory_order_seq_cst。 |

## 返回值说明

| 返回值类型 | 含义 |
| --- | --- |
| `T` | 返回修改前的值。 |

## 约束说明

- 原子对象的类型、地址空间、作用域和内存序必须匹配
- Device 作用域的 64 位对象位于 GM，UB 原子操作仅使用 memory_order_relaxed

## 调用示例

以下片段演示本页接口的基本调用形式；输入和执行上下文须满足本页约束。

```cpp
#include <asc/std/atomic>

decltype(auto) example(asc::std::atomic_ref<int> value)
{
    return value.fetch_and(1, asc::std::memory_order_relaxed);
}
```
