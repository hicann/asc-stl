## 功能说明

头文件路径为：`<asc/std/algorithm>`。

`asc::std::minmax_element` 同时返回范围内最小元素和最大元素的位置；无策略形式在调用者所在执行主体内顺序执行。

标准语义参考：[cppreference `algorithm`](https://en.cppreference.com/w/cpp/header/algorithm)。

## 函数原型

### 原型 1

```cpp
template<class ForwardIterator, class Compare> [[nodiscard]] constexpr pair<ForwardIterator, ForwardIterator> asc::std::minmax_element(ForwardIterator first, ForwardIterator last, Compare comp);
```

### 原型 2

```cpp
template<class ForwardIterator> [[nodiscard]] constexpr pair<ForwardIterator, ForwardIterator> asc::std::minmax_element(ForwardIterator first, ForwardIterator last);
```

## 参数说明

### 原型 1 的参数

**模板参数**

| 参数名 | 描述 |
| --- | --- |
| `ForwardIterator` | 遍历输入范围所使用的迭代器类型；须满足原型要求的遍历能力。 |
| `Compare` | 定义元素先后顺序的比较对象类型。 |

**函数参数**

| 参数名 | 输入/输出 | 描述 |
| --- | --- | --- |
| `first` | 输入 | 输入范围的起始迭代器或指针。 |
| `last` | 输入 | 输入范围的结束位置，不包含该位置。 |
| `comp` | 输入 | 用于确定元素顺序的比较对象。 |

### 原型 2 的参数

**模板参数**

| 参数名 | 描述 |
| --- | --- |
| `ForwardIterator` | 遍历输入范围所使用的迭代器类型；须满足原型要求的遍历能力。 |

**函数参数**

| 参数名 | 输入/输出 | 描述 |
| --- | --- | --- |
| `first` | 输入 | 输入范围的起始迭代器或指针。 |
| `last` | 输入 | 输入范围的结束位置，不包含该位置。 |

## 返回值说明

| 适用原型 | 返回值类型 | 含义 |
| --- | --- | --- |
| 原型 1 | `pair<ForwardIterator, ForwardIterator>` | 返回最小元素和最大元素各自的位置。 |
| 原型 2 | `pair<ForwardIterator, ForwardIterator>` | 返回最小元素和最大元素各自的位置。 |

## 约束说明

- 提供顺序执行且不进行动态内存分配的重载
- 标准执行策略重载采用顺序执行，并遵循标准允许的求值顺序

## 调用示例

以下 Host 片段使用有效整数范围和足够容量的输出缓冲区演示调用。

```cpp
#include <asc/std/algorithm>

decltype(auto) example()
{
    int values[8] = {1, 2, 3, 4, 5, 6, 7, 8};
    return asc::std::minmax_element(values, values + 8);
}
```
