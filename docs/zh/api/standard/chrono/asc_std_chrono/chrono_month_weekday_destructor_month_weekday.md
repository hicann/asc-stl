## 功能说明

头文件路径为：`<asc/std/chrono>`。

`asc::std::chrono::month_weekday::~month_weekday`销毁`month_weekday`对象并结束其生命周期。

标准语义参考：[cppreference `chrono`](https://en.cppreference.com/w/cpp/header/chrono)。

## 函数原型

```cpp
constexpr ~month_weekday() noexcept;
```
