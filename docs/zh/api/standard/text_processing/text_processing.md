# 文本处理库

字符分类、转换和文本格式处理。

| 头文件 | 功能 |
| --- | --- |
| [asc/std/cctype](asc_std_cctype/asc_std_cctype.md) | 提供窄字符分类、大小写判断和大小写转换 |
| [asc/std/charconv](asc_std_charconv/asc_std_charconv.md) | 提供不依赖区域设置的字符序列与数值转换 |
| [asc/std/cuchar](asc_std_cuchar/asc_std_cuchar.md) | 提供多字节字符与UTF-16、UTF-32字符之间的转换 |
| [asc/std/cwchar](asc_std_cwchar/asc_std_cwchar.md) | 提供宽字符类型、转换和宽字符串操作 |
| [asc/std/cwctype](asc_std_cwctype/asc_std_cwctype.md) | 提供宽字符分类、大小写判断和大小写转换 |
| [asc/std/format](asc_std_format/asc_std_format.md) | 提供类型安全的格式字符串解析和格式化功能 |
