## 功能说明

头文件路径为：`<asc/std/cwchar>`。

`asc::std::wcsxfrm`在固定C locale下生成宽字符串排序键。

该接口的可用位置为Host（完整接口）、Device（C locale相关接口）。

标准语义参考：[cppreference `cwchar`](https://en.cppreference.com/w/cpp/header/cwchar)。

## 函数原型

```cpp
namespace asc::std {
size_t wcsxfrm(wchar_t* destination, const wchar_t* source, size_t count) noexcept;
} // namespace asc::std
```

## 参数说明

**函数参数**

| 参数名 | 输入/输出 | 描述 |
| --- | --- | --- |
| `destination` | 输出 | 用于接收结果的目标存储。本调用为同步执行，返回时写入已完成；目标存储在调用期间保持有效即可，且须为待写入内容预留足够空间。 |
| `source` | 输入 | 源数据或源对象。本调用为同步执行，返回时读取已完成；源存储在调用期间保持有效即可。 |
| `count` | 输入 | 参与操作的元素数量。 |

## 返回值说明

| 返回值类型 | 含义 |
| --- | --- |
| `size_t` | 返回转换处理的字符或字节数量，或标准规定的错误、未完成状态编码。 |

## 约束说明

- Host行为遵循系统`<cwchar>`提供的同名接口；字符转换和排序受当前C语言区域设置影响。
- Device固定使用C语言区域设置，按宽字符编码顺序处理，不支持区域设置相关排序规则。

以下片段演示本页接口的基本调用形式；输入和执行上下文须满足本页约束。

}
