# 头文件asc/std/ctgmath

兼容头，组合C++数学与复数重载

## 使用方式

```cpp
#include <asc/std/ctgmath>
```

## API列表

| API | 类型 | C++ 模式 | 可用位置 | 产品支持 |
| --- | --- | --- | --- | --- |

本头文件组合[`asc/std/cmath`](../asc_std_cmath/asc_std_cmath.md)和[`asc/std/complex`](../asc_std_complex/asc_std_complex.md)的C++重载；不提供独立的C语言泛型宏。
