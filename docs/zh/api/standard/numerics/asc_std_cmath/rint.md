## 功能说明

头文件路径为：`<asc/std/cmath>`。

`asc::std::rint` 按当前舍入方式取整；Device 侧适用范围以本页 float 与执行位置约束为准。

该接口的可用位置为 Host、AI Core SIMT 编程。

标准语义参考：[cppreference `cmath`](https://en.cppreference.com/w/cpp/header/cmath)。

## 函数原型

```cpp
float asc::std::rint(float value) noexcept;
```

## 参数说明

**函数参数**

| 参数名 | 输入/输出 | 描述 |
| --- | --- | --- |
| `value` | 输入 | 参与操作或用于初始化、比较的值。 |

## 返回值说明

| 返回值类型 | 含义 |
| --- | --- |
| `float` | 返回按该接口舍入规则得到的浮点值。 |

## 约束说明

- 提供 float 重载和标准 *f 别名，底层能力由 Ascend C 开发套件提供

## 调用示例

以下片段演示本页接口的基本调用形式；输入和执行上下文须满足本页约束。

```cpp
#include <asc/std/cmath>

decltype(auto) example(float value)
{
    return asc::std::rint(value);
}
```
