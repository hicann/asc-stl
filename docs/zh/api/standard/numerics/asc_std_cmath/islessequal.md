## 功能说明

头文件路径为：`<asc/std/cmath>`。

`asc::std::islessequal`按名称指定的浮点比较关系判断输入值，并遵守NaN的无序规则。

该接口的可用位置为Host、AI Core SIMT编程。

标准语义参考：[cppreference `cmath`](https://en.cppreference.com/w/cpp/header/cmath)。

## 函数原型

```cpp
namespace asc::std {
bool islessequal(float x, float y) noexcept;
} // namespace asc::std
```

## 参数说明

**函数参数**

| 参数名 | 输入/输出 | 描述 |
| --- | --- | --- |
| `x` | 输入 | 参与x <= y比较的左操作数（无量纲）；任一操作数为NaN时结果为false且不触发浮点异常。 |
| `y` | 输入 | 参与x <= y比较的右操作数（无量纲）。 |

## 返回值说明

| 返回值类型 | 含义 |
| --- | --- |
| `bool` | 条件成立时返回`true`，否则返回`false`。 |

## 约束说明

- 提供float函数重载、求值类型别名、比较函数、nanf和分类宏。
