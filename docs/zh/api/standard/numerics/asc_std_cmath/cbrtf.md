## 功能说明

头文件路径为：`<asc/std/cmath>`。

`asc::std::cbrtf`计算立方根；Device侧适用范围以本页float与执行位置约束为准。

该接口的可用位置为Host、AI Core SIMT编程。

标准语义参考：[cppreference `cmath`](https://en.cppreference.com/w/cpp/header/cmath)。

## 函数原型

```cpp
namespace asc::std {
float cbrtf(float value) noexcept;
} // namespace asc::std
```

## 参数说明

**函数参数**

| 参数名 | 输入/输出 | 描述 |
| --- | --- | --- |
| `value` | 输入 | 待求立方根的输入值（无量纲）；定义域为全体实数，负数返回负的立方根。 |

## 返回值说明

| 返回值类型 | 含义 |
| --- | --- |
| `float` | 返回立方根；Device侧适用范围以本页float与执行位置约束为准的计算结果。 |

## 约束说明

- 提供float重载、标准 *f别名以及float lerp回移接口。

## 调用示例

以下片段演示本页接口的基本调用形式；输入和执行上下文须满足本页约束。

```cpp
#include <asc/std/cmath>

decltype(auto) example(float value)
{
    return asc::std::cbrtf(value);
}
```
