## 功能说明

头文件路径为：`<asc/std/cmath>`。

`asc::std::expm1`计算自然指数减一；Device侧适用范围以本页float与执行位置约束为准。

该接口的可用位置为Host、AI Core SIMT编程。

标准语义参考：[cppreference `cmath`](https://en.cppreference.com/w/cpp/header/cmath)。

## 函数原型

各重载自C++17起提供。执行位置限定按下列原型分别说明；执行位置宏已省略。

### 原型1

```cpp
namespace asc::std {
[[nodiscard]] constexpr float expm1(
    float value) noexcept;
}
```

可用位置：Host、AI Core SIMT编程。以下constexpr适用于Host；Device声明不带constexpr，调用在运行期执行。

### 原型2

```cpp
namespace asc::std {
template <class Tp, ::asc::std::enable_if_t<__expo_supported_extended_v<Tp>, int> = 0>
[[nodiscard]] constexpr Tp expm1(
    Tp value) noexcept;
}
```

可用位置：Host、AI Core SIMT编程。以下constexpr适用于Host；Device声明不带constexpr，调用在运行期执行。

### 原型3

```cpp
namespace asc::std {
[[nodiscard]] constexpr double expm1(double value) noexcept;
}
```

可用位置：Host。

### 原型4

```cpp

```

可用位置：Host。long double相关重载要求Host启用该类型支持。

可用位置：Host。

## 参数说明

**模板参数**

| 参数名 | 描述 |
| --- | --- |
| `Tp` | 数值类型；须满足对应原型中的整数、浮点或混合算术选择条件。指数与缩放族的扩展浮点选择仅接受可用的half和bfloat16，不接受FP8。 |

未命名的默认int模板形参用于重载选择，调用方无需提供。

**函数参数**

| 参数名 | 输入/输出 | 描述 |
| --- | --- | --- |
| `value` | 输入 | 待计算e^x - 1的指数值（无量纲）；输入接近0时仍保持有效精度。 |

## 返回值说明

返回类型按各原型确定（`float`、`Tp`、`double`、`long double`）。返回e的输入次幂减1，改善接近零时的精度。

## 约束说明

- 指数和缩放族的扩展浮点模板仅接受half和bfloat16；FP8未提供该族扩展重载。

## 调用示例

以下Host示例给出具体输入和预期结果。

```cpp
#include <asc/std/cmath>

bool example()
{
    const auto result = asc::std::expm1(0.0F);
    return result == 0.0F;
}
```
