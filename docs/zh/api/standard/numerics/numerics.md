# 数值库

数学函数、复数、随机数及数值运算。

| 头文件 | 功能 |
| --- | --- |
| [asc/std/cmath](asc_std_cmath/asc_std_cmath.md) | 提供常用标量数学函数和浮点分类功能 |
| [asc/std/ccomplex](asc_std_ccomplex/asc_std_ccomplex.md) | 兼容头，转发至C++复数头asc/std/complex |
| [asc/std/complex](asc_std_complex/asc_std_complex.md) | 提供复数类型、算术运算和复数数学函数 |
| [asc/std/ctgmath](asc_std_ctgmath/asc_std_ctgmath.md) | 兼容头，组合C++数学与复数重载 |
| [asc/std/linalg](asc_std_linalg/asc_std_linalg.md) | 提供面向向量和矩阵视图的线性代数算法 |
| [asc/std/numbers](asc_std_numbers/asc_std_numbers.md) | 提供圆周率、自然常数等标准数学常量 |
| [asc/std/random](asc_std_random/asc_std_random.md) | 提供随机数引擎、分布和随机数生成辅助工具 |
| [asc/std/numeric](asc_std_numeric/asc_std_numeric.md) | 提供归约、扫描、内积、差分和序列生成等数值算法 |
