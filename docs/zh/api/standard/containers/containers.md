# 容器库

序列、关联容器及其适配器。

| 头文件 | 功能 |
| --- | --- |
| [asc/std/array](asc_std_array/asc_std_array.md) | 提供编译期固定长度的连续序列容器 |
| [asc/std/deque](asc_std_deque/asc_std_deque.md) | 提供支持首尾插入和删除的序列容器 |
| [asc/std/forward_list](asc_std_forward_list/asc_std_forward_list.md) | 提供单向链接的序列容器 |
| [asc/std/inplace_vector](asc_std_inplace_vector/asc_std_inplace_vector.md) | 提供容量固定、当前长度可变化的连续序列 |
| [asc/std/list](asc_std_list/asc_std_list.md) | 提供双向链接的序列容器 |
| [asc/std/map](asc_std_map/asc_std_map.md) | 提供按键排序的键值关联容器 |
| [asc/std/mdspan](asc_std_mdspan/asc_std_mdspan.md) | 提供对已有多维数据的非拥有索引视图 |
| [asc/std/queue](asc_std_queue/asc_std_queue.md) | 提供先进先出队列和优先队列适配器 |
| [asc/std/set](asc_std_set/asc_std_set.md) | 提供按键排序且键唯一的关联容器 |
| [asc/std/span](asc_std_span/asc_std_span.md) | 提供对已有连续元素序列的非拥有视图 |
| [asc/std/stack](asc_std_stack/asc_std_stack.md) | 提供后进先出的容器适配器 |
| [asc/std/unordered_map](asc_std_unordered_map/asc_std_unordered_map.md) | 提供基于哈希组织的键值关联容器 |
| [asc/std/unordered_set](asc_std_unordered_set/asc_std_unordered_set.md) | 提供基于哈希组织且键唯一的关联容器 |
| [asc/std/vector](asc_std_vector/asc_std_vector.md) | 提供连续存储并可动态改变长度的序列容器 |
