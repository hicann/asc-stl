# 语言支持库

基础类型、特性宏、源码位置与语言设施。

| 头文件 | 功能 |
| --- | --- |
| [asc/std/cfloat](asc_std_cfloat/asc_std_cfloat.md) | 提供浮点类型精度、范围和表示特征宏 |
| [asc/std/climits](asc_std_climits/asc_std_climits.md) | 提供基础整数类型的取值范围宏 |
| [asc/std/cstddef](asc_std_cstddef/asc_std_cstddef.md) | 提供`size_t`、`ptrdiff_t`、`nullptr_t`和`byte`等基础类型 |
| [asc/std/cstdint](asc_std_cstdint/asc_std_cstdint.md) | 提供有符号和无符号定宽整数类型 |
| [asc/std/exception](asc_std_exception/asc_std_exception.md) | 提供异常基础类型、终止处理和当前异常查询功能 |
| [asc/std/compare](asc_std_compare/asc_std_compare.md) | 提供三路比较结果类别和比较辅助工具 |
| [asc/std/new](asc_std_new/asc_std_new.md) | 提供内存分配函数声明、placement new和相关类型 |
| [asc/std/limits](asc_std_limits/asc_std_limits.md) | 提供数值类型的最小值、最大值、精度和表示属性 |
| [asc/std/source_location](asc_std_source_location/asc_std_source_location.md) | 提供文件名、函数名、行号和列号等源码位置描述 |
| [asc/std/version](asc_std_version/asc_std_version.md) | 提供标准功能对应的特性检测宏 |
| [asc/std/ciso646](asc_std_ciso646/asc_std_ciso646.md) | 提供`and`、`or`、`not`等运算符的C兼容拼写 |
| [asc/std/cstdalign](asc_std_cstdalign/asc_std_cstdalign.md) | 提供对齐关键字的C兼容定义 |
| [asc/std/cstdbool](asc_std_cstdbool/asc_std_cstdbool.md) | 提供布尔类型的C兼容定义 |
