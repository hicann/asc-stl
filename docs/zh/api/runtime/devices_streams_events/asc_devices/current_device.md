## 功能说明

头文件路径为：`<asc/devices>`。

`asc::current_device`查询当前线程的Runtime Device，并在成功时把对应的`device_ref`写入输出参数。

## 函数原型

```cpp
namespace asc {
bool current_device(asc::device_ref& output) noexcept;
} // namespace asc
```

## 参数说明

**函数参数**

| 参数名 | 输入/输出 | 描述 |
| --- | --- | --- |
| `output` | 输出 | 提供“查询当前线程的Runtime Device，并在成功时把对应的`device_ref`写入输出参数”使用的对象引用；被引用对象须在调用期间有效。 |

## 返回值说明

| 返回值类型 | 含义 |
| --- | --- |
| `bool` | 条件成立时返回`true`，否则返回`false`。 |

## 约束说明

- 仅可在Host查询或选择Device。
- 引用只保存设备序号且不拥有Runtime状态。
- 查询失败时输出参数保持原值，属性仅限当前接口列出的AI Core、Vector Core、Warp、UB、GM、L2与架构字段。

## 调用示例

以下片段演示本页接口的基本调用形式；输入和执行上下文须满足本页约束。

```cpp
#include <asc/devices>

decltype(auto) example(asc::device_ref& output)
{
    return asc::current_device(output);
}
```
