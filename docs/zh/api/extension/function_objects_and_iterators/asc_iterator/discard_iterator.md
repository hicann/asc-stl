## 功能说明

头文件路径为：`<asc/iterator>`。

`asc::discard_iterator` 接收写入但丢弃赋值结果的输出迭代器。

## 声明

```cpp
class asc::discard_iterator
```

## 约束说明

- 提供惰性、非拥有的迭代器适配器及其工厂
- 操作数必须在当前执行位置有效
