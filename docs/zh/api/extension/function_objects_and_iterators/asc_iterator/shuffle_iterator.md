## 功能说明

头文件路径为：`<asc/iterator>`。

`asc::shuffle_iterator` 按确定性映射重排索引后访问底层随机访问迭代器。

## 声明

```cpp
template<class Index, class Bijection> class asc::shuffle_iterator
```

## 约束说明

- 提供惰性、非拥有的迭代器适配器及其工厂
- 操作数必须在当前执行位置有效

## 调用示例

以下片段用具体模板实参实例化类型；实际对象仍须满足本页构造与生命周期约束。

```cpp
#include <asc/iterator>
#include <asc/std/cstddef>
#include <asc/std/array>
#include <asc/std/cstddef>
#include <asc/std/cstdint>
#include <asc/std/iterator>
#include <asc/std/type_traits>
#include <asc/std/utility>

void use_type()
{
    using selected = asc::shuffle_iterator<asc::std::size_t, asc::std::size_t (*)(asc::std::size_t)>;
    (void)sizeof(selected);
}
```
