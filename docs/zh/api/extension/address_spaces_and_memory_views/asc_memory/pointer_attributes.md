## 功能说明

头文件路径为：`<asc/memory>`。

`asc::pointer_attributes` 保存指针所处内存空间、Host/Device 可访问性以及所属分配的字节数。

## 声明

```cpp
class asc::pointer_attributes
```

## 约束说明

- 属性对象仅描述查询结果，不拥有或延长指针及其底层分配的生命周期
