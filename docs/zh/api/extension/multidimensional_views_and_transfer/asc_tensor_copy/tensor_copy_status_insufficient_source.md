## 功能说明

头文件路径为：`<asc/tensor_copy>`。

`asc::tensor_copy_status::insufficient_source` 表示源视图不足以覆盖 Descriptor 所需元素。

## 声明

```cpp
asc::tensor_copy_status::insufficient_source = 4
```

## 约束说明

- 描述符及状态词汇可在 Host、AI Core SIMD 编程 和 AI Core SIMT 编程中使用
- Rank 为 1 至 5
- 维度和步长采用 uint32_t，校验零维、零步长、大小溢出与对齐要求，校验本身不启动异步搬运
