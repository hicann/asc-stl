## 功能说明

头文件路径为：`<asc/warp>`。

`asc::lane_mask::all_greater` 返回 Lane 编号大于当前 Lane 的掩码。

## 函数原型

```cpp
static asc::lane_mask asc::lane_mask::all_greater() noexcept;
```

## 参数说明

无参数。

## 返回值说明

| 返回值类型 | 含义 |
| --- | --- |
| `asc::lane_mask` | 返回Lane 编号大于当前 Lane 的掩码。 |

## 约束说明

- 仅可在 AI Core SIMT 编程中调用
- 参数类型、取值范围、会合要求和对象生命周期必须满足页面声明
