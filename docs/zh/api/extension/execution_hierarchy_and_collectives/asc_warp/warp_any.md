## 功能说明

头文件路径为：`<asc/warp>`。

`asc::warp_any` 判断当前 Warp 是否至少有一个活动 Lane 谓词为 true。

## 函数原型

```cpp
bool asc::warp_any(bool predicate) noexcept;
```

## 参数说明

**函数参数**

| 参数名 | 输入/输出 | 描述 |
| --- | --- | --- |
| `predicate` | 输入 | 用于判断元素是否满足条件的可调用对象。 |

## 返回值说明

| 返回值类型 | 含义 |
| --- | --- |
| `bool` | 条件成立时返回 `true`，否则返回 `false`。 |

## 约束说明

- 仅可在 AI Core SIMT 编程中调用
- 所有参与的活动线程必须以收敛控制流调用

## 调用示例

以下片段聚焦当前接口的调用；输入、资源和执行上下文须满足本页约束。

```cpp
#include <asc/warp>

__aicore__ decltype(auto) example(bool predicate)
{
    return asc::warp_any(predicate);
}
```
