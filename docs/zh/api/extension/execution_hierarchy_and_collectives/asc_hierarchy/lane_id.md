## 功能说明

头文件路径为：`<asc/hierarchy>`。

`asc::lane_id` 返回当前线程在 Warp 内的 Lane 编号。

## 函数原型

```cpp
unsigned int asc::lane_id() noexcept;
```

## 参数说明

无参数。

## 返回值说明

| 返回值类型 | 含义 |
| --- | --- |
| `unsigned int` | 返回当前执行单元在所属层级中的索引。 |

## 约束说明

- 仅可在 AI Core SIMT 编程中调用
- 参数类型、取值范围、会合要求和对象生命周期必须满足页面声明

## 调用示例

以下片段演示本页接口的基本调用形式；输入和执行上下文须满足本页约束。

#include <asc/hierarchy>

__aicore__ decltype(auto) example()

    return asc::lane_id();
