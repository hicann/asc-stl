# 位操作、数学与数值计算、伪随机数

位运算、数学工具、数值运算和随机数。

| 头文件 | 功能 |
| --- | --- |
| [asc/bit](asc_bit/asc_bit.md) | 提供无符号32位和64位整数的位反转、掩码生成、位域提取与插入操作 |
| [asc/cmath](asc_cmath/asc_cmath.md) | 提供整数除法取整、对数、平方根、乘积高位和整数幂，以及 Host 和 AI Core SIMT 编程可用的 `sincos` 函数 |
| [asc/numeric](asc_numeric/asc_numeric.md) | 提供整数溢出检测、饱和计算和窄化类型转换检查 |
| [asc/random](asc_random/asc_random.md) | 提供确定性PCG64伪随机数引擎，以及有限整数域上的确定性双射`random_bijection` |
