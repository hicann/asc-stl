# 头文件asc/utility

`in_range`用于判断值是否位于闭区间，`static_for`用于执行编译期固定次数循环

## 使用方式

```cpp
#include <asc/utility>
```

| --- | --- | --- | --- | --- |

| [asc::static_for](static_for.md) | 函数模板 | C++17+ | Host、AI Core SIMD编程、AI Core SIMT编程 | Ascend 950 |
