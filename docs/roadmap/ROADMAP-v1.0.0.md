# ASC-STL Development Roadmap (v1.0.0 · C++ 标准库能力全量)

> **版本目标**：v1.0.0 · **发布日期**：2026 年 10 月 16 日（10 月第 2 周） · **状态**：按周更新，随 v1.0.0 发布
>
> **总路线图**：[ASC-STL ROADMAP](ROADMAP.md)

ASC-STL 是面向昇腾设备核函数编程的纯头文件 C++ 库。核函数开发需要类型系统、容器与视图、算法、数值、原子与同步等通用 C++ 能力；本版本提供其中与平台无关的 **C++ 标准库能力**——`asc::std` 接口层 16 类标准能力模块的全部公共头，使 Host 与 Device 代码共用同一套公共 Header 组织：写 Kernel 就像写普通 C++。

v1.0.0 的能力随 10 月前两周的代码更新合入：第 1 周更新语言支持、概念、诊断、元编程、通用工具、日期时间和输入/输出等基础模块；第 2 周补齐内存管理、容器、迭代器、范围、算法、字符串、文本处理、数值与并发支持模块，并于 10 月 16 日发布版本。

## Focus

- **类型系统与通用工具**：类型查询与变换、值语义类型、函数对象与错误表示全量提供；
- **顺序算法、迭代器与范围**：全量标准算法、迭代器与基于范围的视图组合；
- **容器与视图**：固定容量容器、动态容器与非拥有视图；
- **字符串与文本处理**：字符串存储与视图、字符分类、数值转换与格式化；
- **数值与时间**：数值算法、数学函数、复数、随机数与时间运算；
- **标准原子与同步**：原子操作与内存序、屏障、信号量与互斥；
- **内存管理与语言支持**：智能指针与分配器、语言支持基础宏与类型。

## 获取与使用

- **使用形态**：纯头文件库，全部公共头以 `<asc/std/...>` 提供、可单独包含，经 CMake `INTERFACE` 目标集成，无需链接库；
